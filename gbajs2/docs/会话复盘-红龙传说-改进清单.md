## 三、改进清单（按杠杆排序）

### P0（直接砍掉一半会话时长）
1. **批量导入循环工具化**：`apply-batch` 命令 = 错误报告 → 常见类自动修复（token 对齐/缺字替换表/无中文重翻标记）→ 重导 → 循环至收敛，输出剩余需人工项。消灭手写 TSV 批次。
2. **机翻后置校验内建**：无中文检测+自动重试；token 丢失自动对齐。在进工程前完成，而非 apply 时拒绝。
3. **缺字处理两件套**：内置替换映射表 + `font-add-glyph`（从系统字体渲染新字形插入空槽并登记码表）。

### P1
4. **skill 脚本路径自洽**：所有 gba-text-translate 脚本用 `__dirname`/env 解析依赖与资产；客户端布局回归测试（在 payload 布局跑一遍 skill 主流程）。
5. **validate 门禁按批次评估**：`--scope import-set`。
6. **rom 导航宏**：`rom_nav`（按键序列+帧间条件等待）或 skill 配方"到标题/菜单 X 的标准序列"，替代 91 次手工按键。

### P2
7. import-latest.json 每条失败附建议动作；错误分类统计汇总。
8. bash heredoc 转义问题的替代：提供参数化脚本（避免 agent 现场写 python），或至少在 SKILL.md 给"长脚本写入文件再执行"的规范。
